# ⚡ FIVEM V3 SUPREME - QUICK REFERENCE

## 🚀 INSTANT START GUIDE

### Installation (30 seconds):
1. Edit > Preferences > Add-ons > Install
2. Select `fivem_pipeline_v3_supreme.py`
3. Enable checkbox
4. Press **N** → Find "FiveM V3" tab

## 🎨 LOD PRESETS

```
HIGH (50%, 25%, 12%)
→ Hero assets, close-up objects

BALANCED (40%, 20%, 8%)
→ Most objects, default choice

PERFORMANCE (30%, 15%, 5%)
→ Background objects, optimization priority

ULTRA (20%, 10%, 3%)
→ Far distance objects, extreme optimization
```

## ⚠️ COMMON MISTAKES

```
❌ Not applying scale
   → Always apply scale!

❌ Skipping validation
   → Always validate before export

❌ Ignoring poly budget
   → Check stats regularly

❌ No LODs
   → Generate 3 LOD levels minimum

❌ No collision
   → Always create collision meshes

❌ Texture too large
   → Keep under 2K for most assets

❌ Wrong naming
   → Use proper GTA V prefixes
```
